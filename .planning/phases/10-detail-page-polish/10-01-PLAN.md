### Task 1: Create `FieldRow.jsx` component
**File**: `frontend/src/components/FieldRow.jsx` (CREATE)
**Action**: Create a new shared component with the following exact implementation:

```jsx
export function FieldRow({ label, value }) {
  const isEmpty =
    value === null ||
    value === undefined ||
    (typeof value === 'string' && value.trim() === '') ||
    (Array.isArray(value) && value.length === 0);

  return (
    <div className="grid grid-cols-[140px_1fr] gap-2 items-start">
      <span className="text-xs uppercase tracking-wide text-muted-foreground">
        {label}
      </span>
      <span className="text-sm">
        {isEmpty ? '\u2014' : value}
      </span>
    </div>
  );
}
```

Key rules per CONTEXT.md decisions:
- **D-01**: Named export `FieldRow`. Props: `label` (string), `value` (any).
- **D-02**: Grid layout `grid-cols-[140px_1fr] gap-2 items-start`. Fixed 140px label column.
- **D-03**: Em-dash fallback triggers on `null`, `undefined`, empty string (after trim), and empty arrays. Zero (`0`) must display as `'0'` -- NOT as em-dash. The `'\u2014'` is the em-dash character.
- Label uses `text-muted-foreground` (matches existing pattern in the codebase, equivalent to `~#64748b`).
- Value renders in a `<span>` with `text-sm` for consistency.

### Task 2: Add `.detail-tabs` CSS override to `styles.css`
**File**: `frontend/src/styles.css` (MODIFY)
**Action**: Inside the existing `@layer utilities { ... }` block (after the `.surface-grid` rule), add the `.detail-tabs` class. The shadcn Tabs component uses Radix UI primitives which render `data-state="active"` and `data-state="inactive"` attributes on trigger elements.

Add this CSS block:

```css
.detail-tabs {
  background: transparent;
  border-radius: 0;
  padding: 0;
  border-bottom: 1px solid #e2e8f0;
}

.detail-tabs > button {
  border-radius: 0;
  border-bottom: 2px solid transparent;
  box-shadow: none;
  background: transparent;
  color: #64748b;
  padding-bottom: 0.5rem;
  margin-bottom: -1px;
}

.detail-tabs > button:hover {
  color: #1a3868;
}

.detail-tabs > button[data-state="active"] {
  border-bottom: 2px solid #1a3868;
  color: #1a3868;
  font-weight: 600;
  box-shadow: none;
  background: transparent;
}
```

Key rules per CONTEXT.md:
- **D-05**: Removes default shadcn TabsList pill background (`background: transparent`), adds `border-bottom: 1px solid #e2e8f0`. Active trigger: `border-bottom: 2px solid #1a3868; color: #1a3868; font-weight: 600`. Inactive: `color: #64748b` with hover `color: #1a3868`.
- The `margin-bottom: -1px` on triggers ensures the active trigger's 2px border overlaps the container's 1px border cleanly.
- `box-shadow: none` and `background: transparent` override shadcn's default `data-[state=active]:bg-background` and `data-[state=active]:shadow` styles.
- Use `> button` selector (Radix renders TabsTrigger as `<button>`).
